# Simple Product Picks

Independent UK buying guides for tech accessories - USB-C chargers, hubs and docks,
power banks, cables and adapters.

**Live site: https://simpleproductpicks.co.uk/**

## What this is

Simple Product Picks is a UK-focused review site. Every recommendation is checked
against the live Amazon UK listing so links land on the exact product described, and
every pick is scored on our own published rubric (the SPP Score /10) - independent of
anyone else's ratings. No prices, no star ratings, no sponsored placements.

## Tech

Fully static site (plain HTML/CSS/JS, no framework, no trackers, no cookies) served
via GitHub Pages. Dark mode, structured data (Product, Review, FAQ, Breadcrumb), and
a deterministic build pipeline that renders content at build time.
